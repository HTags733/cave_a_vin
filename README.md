# cave_a_vin REDIAN SHIMA
### Projet évaluée de l'exercise cave à vin
le projet doit comporter :
- Un diagramme UML compréhensible par tous et savoir l'expliqué correctement
- Un code python avec des commentaire pour une bonne relecture de code
- une base de données instancié avec sqlite
- un site-web Flask

4 séance de 4 heure sont mis à disposition

Pour lancer le site en local --> faite play sur le fichier python app.py pour que le site soit accessible. 
http://127.0.0.1:5000 ou http://localhost:5000

### Prérequis

installer les extensions PlantUML de jebbs et PlantUML Viewer de BenkoSoftware.

Les extensions du requirements.txt sont à installer également.

### Guide de l'application

#### Page de connexion

Vous possedez des identifiants appuyer sur se connecter sinon un bouton créer un compte et disponible, inscriver-vous via ce formulaire et connecter-vous.

#### Section disponible

Tableau de bord : Basiquement le dashboard vous présentera les étagères que vous pouvez créer ou supprimer, il y' a également les statistiques de vos étagères.

Catalogue & Ajout : Vous pouvez retrouvez le catalogue de tous les vins disponible en ligne sur le site, vous pouvez ajoutez également un exemplaire dont vous êtes en possesion et renseigné dans les différent champs les informations sur le vin en question.

Mon Stock : Ici vous aurez l'aperçu du stock de vos bouteille ainsi que l'accessibilité de déplacer les vins dans une autre étagère pour une meilleur gestion ou bien les retirés du stock ou les archivés avec une notation pour les dégustation.

Historique : C'est ici que vous retrouverez les dégustations des vins que vous avez goûtez individuellement.

Communauté : L'espace communautaire vous permet d'avoir un aperçu de tous les vins sur lequel plusieurs personnes peuvent données leur propre avis dont le vôtre si vous en avez fait la dégustation.
